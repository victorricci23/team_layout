## Overview

![screenshot](https://media.discordapp.net/attachments/1464634656463786118/1568730011928760351/Captura_de_tela_de_2026-11-07_17-52-28.png?ex=6af0e12c&is=6aef8fac&hm=6a6d4db7af23d004c90ea3453c17f5c790c5c46d5afe5f4b19862579769155dd&=&format=webp&quality=lossless)

Responsive "Meet the Team" section built with pure HTML and CSS. It presents an introductory card followed by team member cards in a grid layout that adapts from a single column on mobile to 3 and 4 columns on larger screens.

### What I learned

- How to create a responsive grid layout using CSS Grid with different breakpoints (`1024px` and `1280px`)
- Positioning text and gradient overlays on top of images using `position: relative` + `absolute`
- Using `srcset` and `sizes` for responsive images
- Working with `clamp()` for fluid padding and spacing
- Creating consistent card designs with different background colors while keeping the same structure
- Handling aspect ratios and object-fit for images inside the cards

### Useful resources

- [CSS Grid Guide - CSS-Tricks](https://css-tricks.com/snippets/css/complete-guide-grid/) - Helped structure the responsive grid
- [MDN - Responsive images](https://developer.mozilla.org/en-US/docs/Learn/HTML/Multimedia_and_embedding/Responsive_images) - Clarified the use of `srcset` and `sizes`
- [Google Fonts - Outfit](https://fonts.google.com/specimen/Outfit) - Font used in the project

### Built with

- Semantic HTML5 markup
- CSS custom properties (limited)
- Flexbox
- CSS Grid
- Responsive images (`srcset` + `sizes`)
- Google Fonts (Outfit)

## Features

- Fully responsive team section (mobile → tablet → desktop)
- Introductory card with decorative background
- 5 team member cards with photo, name and role
- Gradient overlay on each member card
- "See all members" call-to-action card
- Clean and modern card-based design
